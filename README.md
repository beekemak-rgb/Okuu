# Окуучунун дептери

Приложение для изучения и практики Ислама: ханафитский фикх и матуридитская акыда. Работает на телефоне и компьютере, в том числе без интернета. Все записи хранятся на устройстве пользователя. Сам код в репозитории открыт, а личные записи туда не попадают.

## Как выложить на GitHub Pages (бесплатно)

Лучше делать с компьютера: с телефона неудобно загружать папку `icons`.

1. **Аккаунт.** Зарегистрируйтесь на github.com (Sign up). Имя пользователя войдёт в адрес приложения.
2. **Репозиторий.** Нажмите «+» вверху справа → New repository.
   - Repository name: `Okuu` (адрес будет `https://beekemak-rgb.github.io/Okuu/`).
   - Выберите **Public**: на бесплатном тарифе GitHub Pages работает с открытыми репозиториями.
   - Нажмите Create repository.
3. **Файлы.** Распакуйте архив. На странице репозитория нажмите ссылку **uploading an existing file** (или Add file → Upload files). Перетащите в окно **всё содержимое** распакованной папки: `index.html`, `sw.js`, `manifest.webmanifest`, `favicon.svg`, `thumb.png`, `README.md` и папку `icons` целиком. Внизу нажмите **Commit changes**.
4. **Включить сайт.** Settings → Pages. В разделе Build and deployment выберите Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
5. **Подождать 1–2 минуты** и обновить страницу Settings → Pages: вверху появится адрес вида `https://ИМЯ.github.io/okuuchu/`.

## Установка на телефон

- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение» или «Добавить на главный экран». Ещё можно нажать кнопку в разделе Настройки → «Установить на телефон».
- **iPhone (Safari):** откройте адрес → кнопка «Поделиться» → «На экран „Домой“».

Первый раз приложение нужно открыть с интернетом. Потом оно работает и без него.

## Перенос записей из версии в Claude

1. В версии в Claude: Настройки → «Скачать копию (JSON)».
2. В новом приложении: Настройки → «Восстановить из копии (JSON)» → выбрать этот файл.

## Важно про записи

- Записи хранятся только на том телефоне или в том браузере, где вы их делали. У каждого человека свои записи.
- Раз в неделю делайте Настройки → «Скачать копию». Приложение само напомнит об этом на экране «Сегодня».
- Если поменять адрес сайта (например, позже купить домен), на новом адресе приложение откроется пустым. Записи переносятся через копию.

## Как обновлять

1. Замените `index.html` новой версией: Add file → Upload files → Commit changes.
2. В файле `sw.js` увеличьте номер версии в первой строке кода: `depter-v1` → `depter-v2`. Иначе телефоны могут ещё какое-то время показывать старую версию.
3. Через 1–2 минуты обновление придёт на телефоны при следующем открытии с интернетом.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: интерфейс, данные программы, переводы, логика |
| `sw.js` | работа без интернета |
| `manifest.webmanifest` | название, цвета и значки для установки |
| `icons/`, `favicon.svg` | значки приложения |
| `thumb.png` | картинка-превью для ссылок |
